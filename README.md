## Quick start

```tsx
import { TextBox } from 'najwer23morsels/lib/TextBox';

export const Example = () => {
  return (
    <TextBox color="grey" mobileSize={20} desktopSize={20}>
      Hello!
    </TextBox>
  );
};
```

👉 Browse all components in the **[live Storybook](https://najwer23.github.io/najwer23morsels)**.


## Features

- Reusable, customizable UI components
- Written in TypeScript with full type definitions
- Styled with CSS Modules, so there are no global style conflicts
- Per-component imports, so you only bundle what you use
- Responsive props (e.g. separate mobile and desktop sizes)
- Documented and testable in Storybook
